

Vite ist ein modernes Build-Tool und Entwicklungsserver für Webprojekte, das von den Erfindern von Vue.js entwickelt wurde, um schnellere Entwicklungsprozesse zu ermöglichen

- Entwicklungsumgebung für Frontend-Entwicklung
- **_Vite Command Line Interface_** (_**Vite CLI**_) ist eine Zusammenstellung von Werkzeugen für den Build-Prozess komponentenbasierter Vue-Anwendungen (und denen anderer Frameworks)
- **_Build-Prozess_**: Erstellungsprozess, also das Kompilieren von Code und die Einbindung von Bibliotheken (z.B. Vue- oder Boostrap-Umgebung in JS und CSS, andere Komponenten) 
- Vite CLI erfordert die Installation eines nodeJS-Servers
- Hinweis: Stackblitz hat vite integriert
- Das Editieren von `**.vue**`-Dateien erfordert die Installation von Erweiterungen in Brackets und Visual Studio Code
